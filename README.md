# sinkhtml

Sink encode/decode helpers for html payloads in pipelines.

**Site:** https://theworker02.github.io/sinkhtml/

## Install / run

```bash
git clone https://github.com/theworker02/sinkhtml.git
cd sinkhtml
node src/cli.js
node --test
```
